# Customer_shopping_behaviour_analysis
Data Analytics project to analyze the shopping behaviour of customers using Python, MySQL and Power BI. This project includes these steps: Data cleaning and processing using Python (Pandas and Numpy Packages), Data querying using SQL and Dashboard development using Power BI.

## 🔄 Project Flow

Raw Data → Python → SQL → Power BI → Insights

1. **Data Collection** – Imported the customer shopping behaviour dataset.
2. **Data Cleaning & EDA (Python)** – Cleaned, transformed, and explored the data using Pandas, NumPy.
3. **Data Analysis (SQL)** – Used SQL queries to analyze customer behaviour, purchasing patterns, and key business metrics.
4. **Dashboard (Power BI)** – Built an interactive dashboard to visualize KPIs, customer segments, product performance, and shopping trends.
5. **Insights & Recommendations** – Derived actionable business insights from the analysis to support data-driven decision-making.
